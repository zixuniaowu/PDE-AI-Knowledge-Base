PDE はまだ統一された職種名がない新しい仕事。だから市場を見るときは「肩書き」ではなく**仕事内容**で追う必要がある。このページは 2026 年 9 月時点の調査メモで、数字は各ソースの記載をそのまま転記したもの（将来変わる）。

## 結論から

- **海外**: すでに正式職種として採用が進む。Design Engineer / Product Design Engineer として、AI・リーガルテック・会議ツール・セキュリティ・採用 SaaS など幅広い業界で募集。基本給 **12〜16 万ドル**の公開例があり、紹介記事では最高 **22 万ドル**とされる
- **日本**: 職種名は未統一だが仕事は出始めている。「AI プロダクトデザイナー」「UX/UI デザイナー（AI/Agent 方向）」などの名義で、**多くは設計側のみ**。コードが本番リポジトリに入る PDE 完全版は希少 = 需要の空白
- **フリーランス**: フリーランススタート（44 万件超の案件検索サイト）など主要プラットフォームに **AI エンジニア**カテゴリが存在。AI/ML 人材の月単価は同経験年のバックエンドより**約 2 割高**の報告あり

## 需要が生まれている理由

1. **AI ツールが「作れる」を安価にした**: Claude Code / Cursor / v0 により、デザインからコードへの変換コストが激減。誰が作るかより、何を作るか・どこまで仕上げるかが差別化になる
2. **AI 製品は静的なデザイン稿で表現できない**: ストリーミング出力・長い待機・不確実な結果・失敗時の状態。動くプロトタイプを作って確かめられる人間が必要
3. **小チームは引き継ぎが滅びる**: PM → デザイナー → エンジニアの 3 連待ちで 2 週間消える。一人で回せる PDE はリードタイムを桁で短くできる
4. **提示詞エンジニアの次**: 「プロンプトだけ書く」職種は淘汰が予測され、AI システムの設計・検証・運用まで担う複合職へ収斂する見方が複数ある

## 単価・待遇を決める要素

- **判断権の範囲**: 画面とインタラクションを自分で決められるか（決められない二合一ポストは単価が下がる）
- **コードの行き先**: 本番リポジトリ + PR レビューがあるか。静的納品のみはデザイナー扱い
- **商流**: 直請けかエージェント経由か（フリーランス一般と同じく数割の差）
- **実績の形**: 「デザイン過程 + 稼働する製品 + コードリポジトリ」の 3 点セットを見せる仕事が高単価

## 探し方（肩書きで探さない）

**国内**: 「AI プロダクトデザイナー」「AI 体験デザイナー」「UX/UI + AI Agent」「プロダクトデザイナー + React」「フロントエンド + デザインシステム」。※「PDE」で検索するとハードウェア・機械設計が出るので注意

**海外**: Product Design Engineer / Design Engineer / UX Engineer / Design Technologist / Prototyping Engineer / Product Engineer / Founding Product Designer（+ code 条件）

見つけたら確認する 5 点: ①ユーザーと課題の理解が求められるか ②フロー・インタラクションの決定権 ③React/TypeScript 等の実装 ④コードが本番に入るか ⑤リリース後のデータと反応を見る文化。
